# 🍯 NectarNest

A modern and responsive honey brand website built using **React + Vite**.  
This project showcases a premium honey product landing page with beautiful UI, smooth design, and product-focused sections.

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/rajatydv001/nectarNest.git
```

Move into the project folder:

```bash
cd nectarNest
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
